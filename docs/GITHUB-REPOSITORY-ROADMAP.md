# Public repository roadmap

The public SYNBAI ecosystem should make the research workflow inspectable without exposing private services, credentials or user data.

## Recommended repositories

- **synbai-nexus-seo** — public landing pages, SEO metadata, release notes and public research documentation.
- **synbai-nexus-examples** — deterministic sample inputs, presets and sanitized output reports.
- **synbai-nexus-mt5-link** — connector documentation and export contracts.
- **synbai-research-notebooks** — reproducible notebooks for validation and robustness analysis.
- **synbai-strategy-reports** — dated, sanitized research packets with assumptions and rejection logs.

## Repository standards

Each public repository should contain:

- a clear one-sentence description;
- a useful README with a first successful run;
- a license and contribution guide;
- issue templates for reproducibility and documentation;
- a changelog;
- deterministic examples with no API key requirement;
- explicit data, licensing and risk disclosures.

Do not publish account databases, private keys, environment files, user results, broker credentials or unreviewed binary dependencies.
